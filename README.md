# 🛡️ Aegis-Recon

**Modular Security Reconnaissance Framework for Termux**

Aegis-Recon is a lightweight, async-first security reconnaissance framework designed for Termux.

## ✨ Features
- Async Architecture
- Modular Design
- Scope Guard

## 🚀 Quick Start
```bash
pip install -e .
aegis scan [https://example.com](https://example.com) -m headers
```
